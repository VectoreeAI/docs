Vectoree Cloud is a backend for coding agents and the apps they ship. This launch includes a **model gateway** (OpenAI-compatible), **Auth**, **Database**, and **Storage**, plus an organization wallet you top up to pay for model usage.

The agent path is **Skill \+ CLI**. There is no MCP server in this launch.
