## Billing

**Does it cost money?**  
Sign-up is free. Model calls are billed per token. This launch uses a prepaid wallet — you top up before using paid models.

**How do I top up?**  
Dashboard > **Organization > Billing** > Stripe checkout. The amount enters the org wallet.

**What if my balance runs out?**  
Model and tool calls return a clear insufficient-balance error. Top up to resume.

**Where do I see pricing?**  
Dashboard > **Model Plaza**. Each model shows its unit price per 1M tokens.

**Did the $5.00 welcome credit arrive?**  
Connection and the welcome credit are separate. A successful connect binds the workspace even when the $5.00 is not issued.

`🟢 Project Successfully Connected!` means the workspace is bound. When the credit is not issued, one of these usually applies:

1. **Not the org Owner (team member connecting)**  
   Welcome credit is org-level. Members connecting to a shared project use the existing shared balance — a second personal grant is not issued.

2. **Organization already funded (Org Funded)**  
   The $5.00 credit is for unpaid, first-time orgs. A prior top-up or card-on-file marks the org as paid, so the free grant does not apply.

3. **Device or account grant limit (Device/Account Limit)**  
   The credit is once per real device (MAC/IP) and once per account lifetime. A later connect still binds the workspace; the payout is skipped silently.

4. **Email not verified (Email Unverified)**  
   Unverified or disposable emails hold the grant. Verify (or bind a regular address in account settings) and the balance unlocks in real time.

Check **Organization > Billing** on the org that owns the project.

## Connection

How to connect: [Connection](/connect).

**Header still says CONNECT after the agent finished?**  
**Connected** is this account × the project open in the Dashboard. Open that project, then paste the **CONNECT** prompt again in the folder you mean to bind.

**`link` won't connect?**  
Make sure you ran `login` first. Confirm you are in the directory you want to bind to the project.

**Can't log in / no verification code?**  
Check your spam folder. If the issue persists, confirm the platform SMTP is configured and contact support.

**Key invalid error?**  
Check that the key is complete, not deleted, and belongs to the current project.

**Unauthorized or token expired?**  
Run `npx @vectoree/cli login --force`, then `whoami`, `current`, and `ai status`. If `current` is empty, `link` again. Headless: rotate `VECTOREE_API_KEY`.

## Models

**What are `vectoree/free` and `vectoree/auto`?**  
`free` is a free trial model for testing connectivity. `auto` is smart routing that picks a provider by cost or latency.

**Why does the same model have different prices?**  
Prices vary by call type, region, and time slot (peak / off-peak), matching the upstream provider's pricing.

**Can I use TTS / STT / image / video models?**  
Yes. Use `ai models list --output-modality speech` to find the right slug. Do not send a TTS slug to `ai chat`.

## Data and security

**Where is my data stored?**  
In Vectoree-managed storage (Postgres and object storage). Access is controlled via RLS and private buckets.

**What if my API key leaks?**  
Delete the key in the dashboard immediately and create a new one. Keys belong on your server, never in the browser bundle.

**Can I delete a project?**  
Yes, but deletion is destructive. Follow the dashboard confirmation prompts.
