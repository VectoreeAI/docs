## 1.0.0 — 2026-09-04

Vectoree Cloud 1.0 is the first public release: an out-of-the-box cloud backend built for AI agents. Write your agent locally in Cursor, Claude Code, or Codex, connect in seconds, and get the full cloud stack — no more glue code across five SaaS tools.

**Features**
- **Skill + CLI (the agent's cloud control surface):** run `npx skills add VectoreeAI/vectoree-skills`, then `login` / `link`, so your local coding agent can operate the cloud project directly
- **[Model Gateway](/models) (all-in-one model gateway):** one API key for 36+ leading models (OpenAI, Anthropic, and more), with an OpenAI-compatible API, Model Plaza, `vectoree/auto` routing, plus TTS / STT, image, video, and embeddings
- **Tool Hub (hosted MCP):** out-of-the-box hosted MCP for Web Search and Page Extract, billed from the org wallet — no extra third-party API accounts to manage
- **[Authentication](/auth) (login for your app):** add email OTP and Google sign-in for users of *your* agent app, including multi-tenant sessions
- **[Database](/database) (Postgres per project):** a dedicated PostgreSQL database per project; manage tables, schema, and SQL from the dashboard or CLI
- **[Storage](/storage) (object storage):** buckets with public access or signed private access
- **[PAYG wallet](/billing) (pay as you go, no monthly plan):** Stripe top-up, no forced subscription; model and Tool Hub usage deducts from the org balance

> 💡 **Launch offer:** Auth, Database, and Storage run on shared infrastructure in this launch — free to use, not billed separately.
>
> 📌 *Note: Deploy and in-app Payments are iterating fast and are not in 1.0.*
