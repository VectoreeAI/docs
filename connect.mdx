How would you like to get started? Pick a path, paste the prompt into your coding agent, and stop when the Header reads **Connected**.

**CONNECT** means this account has not verified the current Dashboard project yet.

## I have an existing project

<Steps>
  <Step title="Open that folder">
    Work in the project directory, not a parent folder.
  </Step>
  <Step title="Paste the prompt into your agent">
    In the Dashboard, click **CONNECT**. Copy the prompt and paste it into Cursor, Claude Code, Codex, or any coding agent:

    ```text
    set up https://vectoree.ai/SKILL.md

    Connect Vectoree as the backend for this project.
    Dashboard project: <name> (<projectId>)
    Follow the skill: login, link this directory, then run ai status.
    ```
  </Step>
  <Step title="Confirm">
    The Header on that project reads **Connected**.
  </Step>
</Steps>

## I'm new / Start with a template

<Steps>
  <Step title="Open a coding agent">
    Install and open Cursor, Claude Code, Codex, or another coding agent.
  </Step>
  <Step title="Pick a starter and paste the prompt">
    In Dashboard onboarding, choose DeepTutor, RAGFlow, DeerFlow, or LibreChat. Paste the copied prompt into your agent. It clones the starter, points it at Vectoree, then login / link / `ai status`.
  </Step>
  <Step title="Confirm">
    The Header on that project reads **Connected**.
  </Step>
</Steps>
