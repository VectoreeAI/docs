Pick how you want to start.

Need a coding agent first? Install one, then come back:

- [Claude Code](https://claude.ai/download)

- [GitHub Copilot](https://github.com/features/copilot)

- [Cline](https://cline.bot)

## I have an existing project

Do these 3 steps.

<Steps>
  <Step title="1. Open your project folder">
    Open the folder on your computer. Stay in that folder — not the parent directory.
  </Step>
  <Step title="2. Copy CONNECT and paste it into your agent">
    In the [Vectoree Dashboard](https://vectoree.ai/dashboard):

    1. Look at the **top-left** project switcher. The name you see is the project you are connecting.
    2. Click **CONNECT** at the **top-right**.
    3. Copy **everything** in the window. Do not change any line.
    4. Paste it into Cursor, Claude Code, or Codex.

    The window looks like this. Your third line will show **your** project name and ID — copy that, do not type it yourself:

    ```text
    set up https://vectoree.ai/SKILL.md

    Connect Vectoree as the backend for this project.
    Dashboard project: Default project (xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx)
    Follow the skill: login, link this directory, then run ai status.
    ```
  </Step>
  <Step title="3. Check the Header">
    You are done when the top-right button says **Connected**.
  </Step>
</Steps>

Do these 4 steps. After you clone, you still need step 3 to connect.

  <Step title="2. Clone a starter">

  <Step title="3. Connect the cloned folder">
    Open the folder the agent just cloned. Cloning is not connecting.

    1. In the Dashboard, check the **top-left** project name.
    2. Click **CONNECT** at the **top-right**.
    3. Copy the **whole** prompt. Do not edit the `Dashboard project:` line.
    4. Paste it into your agent **in the cloned folder**.
  </Step>

    You are done when the top-right button says **Connected**.

</Steps>
