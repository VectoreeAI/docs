How would you like to get started?

- **I have an existing project** — Get CLI & Prompt to connect your local codebase instantly. **3 steps.**
- **I'm new / Start with a template** — Set up your AI Agent environment and pick a starter template. **4 steps.**

## I have an existing project

<Steps>
  <Step title="1. How you started">
    You already have a local project. Next you will paste a prompt so the agent can login and link it.
  </Step>
  <Step title="2. Connect in your coding agent">
    Paste the prompt into Cursor, Claude Code, or Codex. Your agent will login and link this project.

    In the [Dashboard](https://vectoree.ai/dashboard), check the **top-left** project name, click **CONNECT** at the **top-right**, and copy the **whole** prompt. Do not edit the `Dashboard project:` line.

    ```text
    set up https://vectoree.ai/SKILL.md

    Connect Vectoree as the backend for this project.
    Dashboard project: Default project (xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx)
    Follow the skill: login, link this directory, then run ai status.
    ```

    The third line in **CONNECT** is already your project name and ID. Copy that. Do not type it from this page.
  </Step>
  <Step title="3. Verify connection">
    We check that the project is linked. You are done when the Header says **Connected**.
  </Step>
</Steps>

## I'm new / Start with a template

<Steps>
  <Step title="1. How you started">
    You do not have a local project yet. First open an agent, then clone a starter. That starter prompt also login and link — then verify.
  </Step>
  <Step title="2. Open a coding agent">
    Make sure a coding agent is installed and open. You will paste a prompt into it next.

    Need to install one?

    - [Claude Code](https://claude.ai/download)
    - [Cursor](https://cursor.com)
    - [GitHub Copilot](https://github.com/features/copilot)
    - [Windsurf](https://codeium.com/windsurf)
    - [Cline](https://cline.bot)
  </Step>
  <Step title="3. Start from a starter project">
    Click a starter to copy its prompt. Paste it in your agent to **clone, login, and link**.

    In the Dashboard, stay on the project in the **top-left**. The onboarding card (or **CONNECT**) fills `Dashboard project:` for you. Copy the prompt from there when you can. Do not type the project ID yourself.
