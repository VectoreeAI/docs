How would you like to get started? Same split as Dashboard onboarding. Paste a prompt into your coding agent, then stop when the Header reads **Connected**.

**CONNECT** means this account has not verified the current Dashboard project yet.

Need an agent? Install and open one, then come back:

- [Claude Code](https://claude.ai/download)
- [Cursor](https://cursor.com)
- [GitHub Copilot](https://github.com/features/copilot)
- [Windsurf](https://codeium.com/windsurf)
- [Cline](https://cline.bot)

## I have an existing project

Open that project folder. In the Dashboard, click **CONNECT**, or copy the prompt below. Paste it into Cursor, Claude Code, or Codex. The agent runs `login`, links this directory, then `ai status`.

```text
set up https://vectoree.ai/SKILL.md

Connect Vectoree as the backend for this project.
Follow the skill: login, link this directory, then run ai status.
```

If the Dashboard modal includes a `Dashboard project: <name> (<projectId>)` line, keep it so the agent links the project you have open.

Done when the Header on that project reads **Connected**.

## I'm new / Start with a template

### Open a coding agent

Make sure a coding agent is installed and open. You will paste a prompt into it next. Still need one? Use the download links above.

### Start from a starter

Click a starter to copy its prompt. Paste it in your agent to clone, login, and link.
