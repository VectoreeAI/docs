<Info>
  即将上线 — 正在开发中。
</Info>

使用你 Agent 的人付给 **你**，钱回到你这边。这样应用才成为可以收费的产品 — 由 Stripe 驱动。

它接在同一项目的 [Deploy](/zh/deploy) 之后：先有公开应用，再有收款方式。

这和 [计费](/zh/billing) 上的组织钱包不是同一条流：

| | 组织钱包 | Payments |
|---|---|---|
| 状态 | 现已上线 | 即将上线 |
| 谁付钱 | 你付给 Vectoree | 你的用户付给你 |
| 用途 | 模型和 Tool Hub 用量 | 使用你上线的应用 |

完整路径见 [概览](/zh/introduction)。
