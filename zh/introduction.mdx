Vectoree Cloud 用来 **构建并打磨你自己的 Agent**，再把它交到其他人手里。

你在本地用 Cursor、Claude Code 或 Codex 写 Agent。Vectoree 是你在这个过程中接上的后端：**Model Gateway**、**Tool Hub**、**Auth**、**Database** 和 **Storage**，都在同一个项目里，从组织钱包扣费。Agent 通过 **Skill + CLI** 操作云端；网页搜索与抽取走托管 MCP。

Agent 就绪后，同一项目会有一个公开 URL（[Deploy](/zh/deploy)），以及让那些人向你付费的能力（[Payments](/zh/payments)）。这两项正在开发，即将上线。

路径就是 Agent。Vectoree 是你接上的那一层，让它能思考、记住，之后再被其他人使用。
